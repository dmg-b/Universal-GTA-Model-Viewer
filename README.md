# UniversalGTAModelViewer

`version beta 0.3`

Универсальный просмотрщик моделей из GTA III, Vice City, San Andreas  
и собственных кастомных моделей

## Возможности

- Просмотр всех оригинальных игровых моделей машин, скинов и оружия из 3D вселенной игр GTA в одном месте
- Смена цветов кузова авто (в т.ч. ручная)
- Приближение/отдаление/перемещение камеры
- Вращение объектов по точным координатам или вручную;
- Интерактивные инструменты предпросмотра: тень, сетка, несколько режимов отображения модели
- Взаимодействие с DFF-древом частей модели
- Скриншоты высокого разрешения в форматах png, jpg, webp, bmp
- Поддержка архивов (7z, rar, zip) с кастомными моделями (dff+txd)
