# UniversalGTAModelViewer

`version beta 0.3`

Универсальный просмотрщик моделей из GTA III, Vice City, San Andreas  
и собственных кастомных моделей

## Возможности

- Просмотр всех оригинальных игровых моделей машин, скинов и оружия из 3D вселенной игр GTA в одном месте
- Смена цветов кузова авто (в т.ч. ручная)
- Приближение/отдаление/перемещение камеры
- Вращение объектов по заданным координатам или вручную с помощью ползунков;
- Интерактивные инструменты предпросмотра: тень, сетка, несколько режимов отображения модели
- Взаимодействие с DFF-древом частей модели
- Скриншоты высокого разрешения в форматах png, jpg, webp, bmp
- Поддержка архивов (7z, rar, zip) с кастомными моделями (dff+txd)

## Примечание

Программа находится на стадии бета-тестирования и готова на 70%.
Известные баги будут полностью исправлены в следующих версиях. Если обнаружили баг, создайте pull-request.

Что предстоит реализовать: 
- переработка UI-интерфейсов разделов «Скриншот», «О программе»
- фикс UI-багов
- функционал анимации моделей по ключам
- функционал анимации отдельных частей модели авто (капот, багажник, двери)
- функционал анимации скинов, предпросмотр анимаций благодаря интеграции .ifp-формата.
